# MAW public CLI — distribution packet

Publication-ready neutral studio copy. This packet does not speak in Cody Haring's first-person voice and does not authorize account creation, paid placement, private-Lab disclosure, or claims beyond the linked source.

## Primary audience

Developers who prefer terminal-native coding tools and want to choose among model providers rather than bind a workflow to one vendor. Secondary audience: technically comfortable Android/Termux users willing to test an explicitly experimental source path.

## Canonical destination

https://ultramonkeydog-studios.vercel.app/maw

## Directory / community listing (100 words)

MAW is a public, multi-provider coding CLI from Ultramonkeydog Studios. It keeps the LLxprt provider, profile, tool, session and extension foundation, while adding its own command identity, source-install workflows and an optional connection to the studio's private Lab. The normal `maw` command works in an ordinary repository without Lab services. The repository documents a Windows source setup and a separate experimental Android/Termux ARM64 path. Users bring their own provider credentials; external model calls may cost money. MAW is source-based development software, not a hosted service or a claim of universal compatibility or unattended autonomy. Source, setup and attribution are public.

## Short listing

MAW is a public multi-provider coding CLI with its own command identity, a standalone Windows source path, an experimental Termux path and optional private-Lab attachment. It retains its LLxprt lineage and makes the evidence boundary explicit.
