## Description body (BBCode)

```bbcode
[h]Thirty-six dogs. Eight weeks. Fights that keep receipts.[/h]

MUTTPIT is an async scrap-league auto-battler about scarred mongrels, exact builds and deterministic fights. Draft a kennel of junk-armored dogs — each with a face, a temperament and a grudge — set every dog's [b]Bite Order[/b], and throw the kennel into the Pit.

[i]Play free in your browser. No account, no launcher, no install. Keyboard or touch.[/i]

[h]What makes it strange[/h]
[list]
[*][b]Bite Order is the build.[/b] The order each dog acts in changes what actually happens — the same two kennels fight differently when one line is rewritten.
[*][b]Every bout keeps receipts.[/b] Resolution is pure deterministic simulation: same kennels, same seed, same event log, same replay hash on any machine. Outcomes arrive as [b]Verdict Packets[/b] that fail audit the moment anyone tampers with them.
[*][b]Play-by-mail is real.[/b] Export a [b]Kennel Code[/b], mail it to a friend (or a rival), import theirs, resolve locally, and exchange the Verdict Packet.
[*][b]The Bone Bracket season.[/b] Eight weeks against ghost kennels with their own names, personalities and schedules. Scars carry between weeks. The ladder climbs.
[/list]

[h]Where it came from[/h]
The public build came together during an unusually compressed production run — roughly 44 hours from repository baseline to the inspected public build — directed by Cody Haring through a private development system, with MAW as an execution surface and Claude Code contributing implementation later in the run. The repository history includes balance measurement, browser-found bugs, deterministic decision tests, art iteration and post-launch repair.

Play first. The receipts are public for anyone who wants the deeper story: [url]https://ultramonkeydog-studios.vercel.app/dispatches/the-pit-keeps-receipts[/url]

[h]Status and limits[/h]
MUTTPIT is a small, free, one-shot studio game — a proof of capability, not a live service or a flagship release. It is actively balanced and repaired in the open. This page does not claim commercial validation, broad device compatibility beyond the tested browser runs, or an esports scene.

[b]Credits[/b] — Design, direction, writing and final acceptance: Cody Haring. Dog and key art: AI-assisted, studio-directed (disclosed above). Engine, simulation, UI and text: authored code.
```
