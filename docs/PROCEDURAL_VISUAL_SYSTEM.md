# Procedural Visual System

Status: active public-site implementation contract

## Purpose

Replace generic glass-dashboard styling and decorative AI imagery with a deterministic studio framing system derived from current project and creator laws.

This system is presentation framing. It is not gameplay capture, concept art, or evidence that a project visual has been integrated into its game.

## Authority chain

1. Current project owners and witnessed media
2. Cody's current direction
3. Creator Memory style and identity guidance
4. Project visual owners, including Savage Crown body-first law
5. Drive studio, brand, marketing, and visual-production owners
6. True Scholar UI-blindness research
7. External references

Ultramonkeydog Studios owns the public website mutation and its proof artifacts. Private production infrastructure remains outside this repository and outside public presentation.

## Shared studio signature

The dominant studio style is **Studio Proof / Creator-Driven Presentation**: public work, honest evidence, project range, and Cody's authorship.

The website must not flatten every property into one skin. Its shared structure is:

- hard-edged print and cartridge framing;
- low-resolution procedural energy;
- visible evidence states;
- interrupted borders, offsets, scars, and color tabs;
- compact readable typography;
- playful creature-like marks instead of sterile network diagrams.

Each property then owns a distinct palette and emotional function. This is the `PROPERTY_SPECTRUM` rule.

## Property spectrum

- WHAT WE FED: living greens, twilight, ivory, ember, beauty before corruption.
- Bone League: bone, blood, cold field light, bruise violet, acid rivalry accents.
- Savage Crown: blood-orange, crown gold, biological cyan, royal mutation colors.
- Saga of an Anxious Fluff: coral, sky, sun yellow, mint, lilac, and emotional optimism.
- Feral Formation: twilight indigo, sunset amber, sea green, field lavender.
- Box o' Battles: ink, cream, comic red, ruling gold, issue blue, variant violet.

These colors remain partitioned by property and function. They must not dissolve into one smooth rainbow gradient or generic neon haze.

## Visual laws

- Character and project identity before effect.
- Authored media stays authoritative; procedural output supplies energy, framing, weather, signal, and transition.
- Hard tone bands instead of smooth airbrushed gradients.
- Ordered dithering instead of bloom fog.
- Low-resolution internal rendering with nearest-neighbor enlargement.
- Color should create wonder, rivalry, mutation, warmth, tactics, or comic judgment—not merely status decoration.
- Angular cuts and interrupted frames instead of rounded glass cards.
- Emissive pixels remain bounded and must not erase typography or evidence.
- No fake telemetry, generated lettering, neural-network diagrams, glowing orb dashboards, cyan-violet SaaS styling, or one-project palette imposed on the whole studio.

## Deterministic field

`ProceduralField.tsx` renders a seeded low-resolution canvas. It combines:

- bounded Lorenz-derived trajectories used as energetic tails;
- stepped line segments rather than smooth curves;
- 4x4 Bayer ordered dithering;
- seeded hard-edged color territories;
- pixel-specimen silhouettes that make the field feel inhabited;
- project-specific six-color palettes;
- static fallback under reduced-motion preference.

The same seed and viewport class must reproduce the same composition. Animation may change a small signal phase only; it must not change layout or obscure content.

## Evidence boundary

Procedural fields are labeled and treated as `STUDIO_GENERATED_FRAMING`. They never replace:

- current screenshots;
- device captures;
- project-owned key art;
- runtime visual acceptance;
- provenance requirements.

## Visual inspection loop

1. Render desktop, tablet, and mobile.
2. Inspect DOM geometry and painted text ranges for clipping, overflow, overlap, and target size.
3. Capture full-page raster output.
4. Inspect grayscale hierarchy and downsampled readability.
5. Compare color-area distribution, property distinction, and whether the page feels alive rather than uniformly severe.
6. Record the proof ceiling: build and browser geometry are not Cody's final taste approval.
