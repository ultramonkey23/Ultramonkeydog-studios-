# Public Truth Order

Status: active Studios presentation contract

## Why this exists

A polished consumer can accidentally outrun the system that owns the claim. That happened when the website presented a sophisticated Box o' Battles card while the Box repository still contained a placeholder evaluator that selected combatant A whenever any evidence string existed.

The correction is not to make the public layer less ambitious. It is to inspect and advance the owner first, then present exactly what the owner has actually produced.

## Required inspection order

Before adding or promoting a public capability claim:

1. inspect repository truth and current main;
2. inspect the owner code that creates the output;
3. inspect schemas, constants, and persistence/replay ownership;
4. inspect tests and runtime or deployment proof;
5. inspect the consumer and its transformation of the owner output;
6. state contradictions, missing evidence, and proof ceiling;
7. only then improve presentation.

## Owner-before-consumer laws

- A consumer must not imply that it calculated an owner-held result.
- A historical or imported packet must state whether the current engine recomputed it.
- A polished card is not proof of a working evaluator.
- Green consumer CI is not owner-engine proof.
- Owner implementation, integration, tests, witnessed operation, calibration, and independent validation remain distinct states.
- Private owner repositories may be cited by short merge identity without publishing inaccessible URLs.
- When owner and consumer truth conflict, narrow the public claim immediately; do not preserve the stronger marketing story.

  a "contradicts the reviewed verdict" panel naming BOB-0003's Darth Vader ruling. Neither is
  promoted over the other, and neither is calibrated.

## Presentation gate

A Studios signal or project card passes this contract only when a reader can tell:

- who owns the capability;
- what artifact or behavior was tested;
- whether the displayed packet was generated by the current owner implementation;
- what remains unproven;
- whether the public site is presenting, transforming, or calculating.
